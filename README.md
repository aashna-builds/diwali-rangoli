# Diwali Rangoli: neon cymatics

An interactive neon-cymatics rangoli for Diwali. Sand-plate (Chladni) patterns fold into a glowing mandala with grain and glitter. The cursor bends the pattern, and the music is synthesized live in the browser (no audio files).

Open `index.html` in Chrome. Click once to start the music.

- Move: bend the sand and play notes
- Click: ripple and a sparkler
- N: change instrument (bansuri / handpan / sitar)
- T: change tune (Aarti / Deepam / Utsav)
- M: music on/off, space: pause, arrows: petals, S: save PNG
